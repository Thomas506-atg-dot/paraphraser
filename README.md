# Rule-Based Paraphraser

A 100% client-side text paraphrasing tool. No AI, no API keys, no network requests — runs fully offline in the browser.

## Features
- 300+ synonym groups with randomized selection
- 40+ phrase-level rewriting rules
- Three rewrite modes: Light, Standard, Strong
- Capitalization-preserving word swaps
- Sentence reordering fallback
- Dark futuristic UI, mobile responsive

## Usage
Open `index.html` in any browser. No build step, no dependencies.
